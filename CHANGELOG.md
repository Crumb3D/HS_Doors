# HS Doors changelog

**1.0.3** — Runs on 7 Days to Die 3.4, and still on 3.2 and 3.3 with the same download. It used to refuse to load on 3.4. 3.4 uses the 3.3 model and network path.

**1.0.2** — Works on 7 Days to Die 3.2 and 3.3. Put the same folder on the dedicated server and every client. Sliding leaves are 2 blocks tall, and the operator housing stays put while the leaves move. New 2-wide sliding operator, with a paintable header fill the same depth as the wall beside the door. Sliding doors play a glass sliding sound when they open and when they close. The Door Setup Tool aims at the door you are looking at, registering a panel names that door, and a small HUD shows while you hold the tool. Mezzanine rails: straight, end left, end right, corner, corner end left, corner end right, and a corner post with no glass panels. Paintbrush: Tarmac and Pillar under Masonry, Supermarket Cladding under Wall Coverings. Revolving drum walls you can stack, including paintable solid shapes. Press R to cycle plate, thick, and glass.

**1.0.1** — Inventory icons for the Unity door pieces. Glass leaves are hittable, so the Door Setup Tool hold-E prompt shows when you aim at them. Dummy model on the hidden glass parent (fixes the XML load crash). Door save no longer blows up on a Unity Vector3 loop.

**1.0.0** — Player-built automatic sliding doors and revolving doors. You place the glass and frames; the setup tool marks the moving parts and a panel.
